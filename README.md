# react-learning

基于 React、TypeScript 和 Vite 的学习项目。

## 开发

```bash
npm run dev
```

默认访问地址为 <http://localhost:5173>。

## 构建

```bash
npm run build
```

## 本地预览构建结果

```bash
npm run preview
```

## 运行语法示例

```bash
npm run example:js
npm run example:ts
```

## 打开 CSS 学习页面

```bash
npm run example:css
```
